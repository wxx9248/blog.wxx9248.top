## 0x01 問題提起

CとPythonの両方を学んだことがあれば、二つの言語で剰余演算子（%）の実装が異なることをご存じでしょう。この違いは、オペランドが**負の数**のときに現れます。

次の二つの例を見てください。

```c
#include <stdio.h>
int main(void)
{
    printf("%d", -8 % 7);
    return 0;
}
```

```python
print(-8 % 7)
```

どちらのプログラムも$-8 \bmod 7$を求めているのに、実行結果は異なります。

- C言語の実行結果は$-1$
- Pythonの実行結果は$6$

## 0x02 原因

C言語とPythonでは、剰余の定義が異なるからです。

- C言語は切り捨てによる剰余（truncated modulus）を使う
- Pythonは床関数による剰余（floor modulus）を使う

剰余演算の定義は次のとおりです。

$$
a \bmod b = a - b \cdot (a \backslash b)
$$

二つの定義では、$a \backslash b$の解釈が異なります。

- 切り捨てによる剰余は、小数部を切り捨てて整数部だけを残す整数除算を使います
- 床関数による剰余は、まず浮動小数点の除算を行い、その結果に床関数を適用する整数除算を使います

## 0x03 結果の検証

以上の原理に沿って、先ほどのCとPythonのコードを検証します。

$-8 \bmod 7$を計算します。

$$
-\frac{8}{7} \approx -1.142857
$$

切り捨てによる剰余：

$$
-8 \bmod 7 = -8 - 7 \times (-8 \backslash 7) = -8 - 7 \times (-1) = -1
$$

床関数による剰余：

$$
\lfloor-1.142857\rfloor = -2
$$

$$
-8 \bmod 7 = -8 - 7 \times (-8 \backslash 7) = -8 - 7 \times (-2) = 6
$$

## 0x04 補足

1. 整数除算でも、CとPythonはそれぞれ対応する実装を使います。
   - C言語では `-8 / 7 == -1`
   - Pythonでは `-8 // 7 == -2`
2. 資料によっては、切り捨てによる剰余を「modulus」ではなく「余り（remainder）」と呼び、床関数による剰余と区別しています。（後者を真の剰余（true modulus）と呼ぶ人もいます）
